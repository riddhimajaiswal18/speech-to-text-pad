Speech-to-Text Studio is a lightweight web application that allows users to convert speech into text in real time using the Web Speech API.

It includes:

🎙️ Live speech transcription (interim + final)

💾 Save transcriptions as notes (stored in localStorage)

🗂 Notes Drawer to view saved notes

🧹 Clear and Stop controls

🚀 Features

🎧 Real-time Speech Recognition

Uses SpeechRecognition / webkitSpeechRecognition to:

Show interim and final transcribed text

Update status bar (Listening, Stopped, Saved, Cleared)

📝 Save Transcripts as Notes

Notes auto-save with timestamp

Stored in browser using localStorage

Rendered dynamically on page load
